## Install / Instalação

### 1) Clone

```bash
git clone https://github.com/manansbdb/editorconfig-presets.git
cd editorconfig-presets
```

### Use / Usar

```bash
cp presets/default.editorconfig .editorconfig
```

### Requirements / Requisitos

- `git`
- No paid services required / Sem serviços pagos

---

## What's included / O que inclui

| File | Style |
|------|-------|
| `presets/default.editorconfig` | 2-space, UTF-8, LF |
| `presets/python.editorconfig` | 4-space for Python |
| `presets/go.editorconfig` | Tabs for Go |

## Usage / Uso

**EN:** Copy a preset to your repo root as `.editorconfig`.

**PT:** Copia um preset para a raiz do repo como `.editorconfig`.

```bash
cp presets/default.editorconfig .editorconfig
```
